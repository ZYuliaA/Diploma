Здесь представлена моя дипломная работа на тему "Классификация произведений известных художников с помощью компьютерного зрения". 

Задача: обучить нейронную сеть на классификацию художников по их картинам с точностью на тестовой выборке выше 80%. 

Стек: Torch, Torchvision, Python (Pandas, Numpy), Sklearn, Matplotlib, Collections.

EDA выявил сильный дисбаланс классов, решением стало применение WeightedRandomSampler. Также к данным применила нормализацию и привела к единому размеру. Для решения поставленной задачи было проведено 7 экспериментов на 3 предобученных моделях. Так как первая модель с настройкой features extraction не обучилась, далее применила настройку fine-tuning. Модели обучались с аугментацией и без на 20 эпохах на GPU с оптимизатором Adam, шагом обучения 1e-4 и функцией потерь cross-entropy.

Результаты: модель efficientnetv2_s с аугментацией смогла достичь точность равную 81.76%, что превысило заданную ранее точность. Исследование, которое было проведено в 2021 году на этом наборе данных, выдало точность равную 77.75%.
